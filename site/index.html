    Usage note

    The test URLs and default stagger are configured at the top of app.js in the CONFIG object.

    Select 4, 8, or 12. Tap Start test. Changing the count after starting tears down every player and creates a clean new set.

    For more than four streams, initialization is staggered by the number shown above. Change it before starting or restarting.

    Green means the player reports active playback. Yellow means it is ready, buffering, paused, autoplay-blocked, or otherwise degraded. Red means the YouTube API reported a failure or unavailable video. Use Retry on an individual stream.
